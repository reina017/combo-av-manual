# combo-av-manual
Scanned PDF of the original Japanese instruction manual for the Combo AV arcade control box.

# View the Manual
[Open the manual (PDF)](combo_av_manual.pdf)

Language: Japanese

# About This Archive
This manual was scanned from a physical copy to help other Combo AV owners use and maintain their hardware.
This is an unofficial archive and is not affiliated with or endorsed by the original manufacturer. All rights to the original manual remain with their respective owners.
